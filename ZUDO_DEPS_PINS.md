# ZUDO_DEPS_PINS

Provenance for artifacts vendored or generated from first-party (takazudo/zudolab) upstreams.
Updated by /dev-bump-zudo-deps on every sync — keep `pinned:` accurate.

## create-zudo-doc

- repo: zudolab/zudo-doc
- what: doc-site scaffold generated by `create-zudo-doc`, then hand-customized. The generator is a
  separate package from the `@takazudo/zudo-doc` runtime library that `doc/package.json` pins, and
  it versions in lockstep with it — the runtime tarball is NOT the scaffold source.
- files: doc/pages/index.tsx, doc/pages/docs/[[...slug]].tsx, doc/pages/[locale]/docs/[[...slug]].tsx,
  doc/src/styles/global.css, doc/tsconfig.json, doc/scripts/check-links.js,
  doc/scripts/setup-doc-skill.sh, doc/zfb.config.ts, doc/setup-preset.json
- source: templates/base/ (pages/, src/styles/, scripts/, tsconfig.json),
  templates/features/i18n/files/pages/[locale]/docs/[[...slug]].tsx,
  dist/zfb-config-gen.js → doc/zfb.config.ts, dist/preset.js → doc/setup-preset.json
- track: releases
- pinned: 86012b98df0b47c942990ddbe91b1629a3657de9 (create-zudo-doc@5.25.0)
- previous-pin: 3d1db253f59cb107a328f6f91a2a3b6301a043fc (create-zudo-doc@5.13.0) — the version that
  produced the original scaffold in commit 6c7eb76. Established by content match, not by guess:
  doc/scripts/check-links.js is byte-identical to the 5.13.0 template after the repo's Prettier
  config, and 5.13.0 was published ~1h before the scaffold commit.
- updated: 2026-09-18
- sync: `npm pack create-zudo-doc@<ver>`, then diff the template paths above against the local
  files and merge by hand. Do NOT re-run the interactive generator over `doc/` — it would
  overwrite the hand-edits below.
- notes:
  - doc/zfb.config.ts `metaTags.ogImage: false` (+ its explanatory comment) deliberately
    contradicts `doc/setup-preset.json`, which still records the generator's `"/img/ogp.png"`.
    That asset does not exist, so the preset value would emit a broken og:image URL.
  - doc/zfb.config.ts `claudeResources` carries `claudeDir: "../.claude"`, `projectRoot: "."` and
    `scanRoot: ".."` (generator emits only `claudeDir: ".claude"`), so generated pages stay under
    `doc/` while the scan covers the repository root.
  - doc/zfb.config.ts `defaultLocaleOnlyPrefixes` must keep `/docs/claude/` alongside the four
    `claude-*` prefixes: zudo-doc >=5.15.0 generates locale-owned Claude resource indexes and
    refuses to overwrite the authored ja stub at `doc/src/content/docs-ja/claude/index.mdx`
    without it. create-zudo-doc 5.25.0 no longer emits this array at all, so a regeneration would
    drop it and break the build.
  - doc/zfb.config.ts site identity is hand-written: `siteName`, `siteDescription`, `githubUrl`,
    `footer.copyright` and the five-entry `headerNav` replaced the generator placeholders.
  - doc/setup-preset.json is the record of the original 5.13.0 generator run and is intentionally
    not rewritten on sync; the 5.25.0 preset schema only adds an optional `additionalLangs` field.
  - doc/pages/**/[[...slug]].tsx carry the generator's docHistory patch (the `DocHistory` /
    `defineChromeBindings` imports) and are Prettier-formatted with the repo's config — both
    diverge from the raw templates and must be re-applied after any re-copy.
