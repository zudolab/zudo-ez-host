This documentation separates product contracts from the instructions used to
develop and operate the Workers. Start with the path that matches your role.

## Choose a path

- Read the [core concepts](../concepts/) to understand projects, machines,
  public URLs, and milestone boundaries.
- Follow [Getting started](./) for the Dropbox-style product model and the
  relationship between a local sync root and a hosted site.
- Use [Local development](./development/) to install dependencies, run both
  Workers, apply local migrations, and choose a test lane.
- Use the [deployment runbook](../hosting/deployment/) only when you are an
  authenticated operator provisioning Cloudflare resources.

## Read the contracts

The [hosting architecture](../hosting/) explains the trust boundary, while
the [sync protocol](../sync/) explains manifests, immutable uploads, and
atomic publication. The [webapp specification](../webapp/) describes
account, project, and machine surfaces without implying that deferred features
are shipped.
